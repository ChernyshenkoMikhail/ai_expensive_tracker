# ai_expensive_tracker

A Telegram/WhatsApp bot allows users to upload photos of store receipts or screenshots from their banking apps. The data is then added to a Google Sheet, which consists of two separate tabs: one for data extracted from banking screenshots and another for data from receipts. These two tabs are linked by a common key, making it possible to determine which specific items from a receipt correspond to a particular transaction shown in a banking screenshot. Two additional tabs serve as dashboards, visualizing the data from the first two sheets.
